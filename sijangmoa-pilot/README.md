# 시장모아 · 1회 공개 구매 의향 실험

천안중앙시장, 온양온천시장, 세종전통시장(조치원) 생활권을 대상으로 하는 **가상 공동구매 수요 조사용 웹사이트**입니다.

## 제공 기능

- 시장별 상품 탐색, 분류 및 검색
- 브라우저에만 저장되는 장바구니 (localStorage)
- 희망 수령 방식 선택 및 구매 의향 선택
- 의향서 생성, 공유 시트 열기, 내용 복사

**상품·가격·할인·참여 인원은 실제 판매 데이터가 아니며 주문·결제·배송을 제공하지 않습니다.** GitHub Pages는 정적 호스팅으로 참여 내용을 서버에 자동 저장하지 않습니다.

## 주변 사람에게 1회 실험하기

1. 사이트 링크와 **응답을 받을 운영자 채팅방**을 함께 전달합니다.
2. 참가자는 관심 있는 시장·상품을 선택하고 장바구니에서 의향서를 만듭니다.
3. 참가자가 **공유하기** 또는 **복사하기**를 눌러 운영자에게 직접 전송합니다.
4. 운영자는 전달된 메시지만 집계하고, 실제 주문이 접수된 것으로 처리하지 않습니다.
5. 실명·전화번호·주소·결제정보는 이 사이트에 입력하거나 의향서에 추가하지 않도록 안내합니다.

권장 측정값: 링크 전달 수, 의향서 수신 수, 시장별 관심 수요, 상품별 수량, 희망 수령 방식, '조건이 맞으면 구매' 응답 비율.
